# 🔐 Password Strength Analyzer & Breach Checker

A full-stack cybersecurity tool that analyzes password strength in real-time and checks if it has been exposed in real-world data breaches.

---

## 🌍 Live Demo
https://password-checker-fizl.onrender.com/

---

## 🚀 Features

- 🔍 Real-time password strength analysis
- 📊 Entropy-based scoring system
- 🚨 Breach detection using Have I Been Pwned API
- 👁️ Show/Hide password toggle
- 🔐 Strong password generator
- 📋 Copy to clipboard feature
- 🌗 Dark / Light mode toggle
- 📜 Password strength history (privacy-safe)
- 🎨 Interactive UI with animated progress bar

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **API:** Have I Been Pwned (HIBP)  
- **Deployment:** Render  

---

## 🔐 Security Concepts Used

- Password complexity rules
- Entropy-based strength calculation
- k-Anonymity model for secure API usage
- Real-world breach detection

---

## ⚙️ How It Works

1. User enters a password  
2. Frontend sends it to backend via API  
3. Backend:
   - Checks strength rules  
   - Calculates entropy  
   - Queries breach API securely  
4. Returns:
   - Strength score  
   - Feedback  
   - Breach status  
5. UI updates in real-time
